Lists grouped your way, names that stay yours, a tidier Settings

Flat lists, grouped your way

One list across all your accounts, grouped by project, platform or organization, in the window, the top bar and the widgets. Each group is a plain heading with its count.

Organizations and projects

Name an organization once, even across GitHub and GitLab, and group your repositories into projects: rename in place, drag to move, disband. It all stays in Source Glance.

Limit repositories and boards

Per account: widen or limit what the sign-in can reach on GitHub, choose the repositories you watch, search public ones to add, and hide the boards you don't need.

Settings, page by page

Accounts, Preferences, Startup and About each have a page. The Accounts card and a Top bar switch are one click away.

See what a glance can do

Short loops drawn from the real app. Pick one, or let them play.

Triage your morning before the coffee's ready

All Tasks pulls every issue, pull request and project card assigned to you, from every GitHub and GitLab account, into one list. Filter by kind, account, label or person, and the list narrows as you click.

Answer a teammate without opening a browser

Press Comment on any item and a Markdown box opens right under it. Write, press Ctrl+Enter, and it's posted; the box tucks itself away and the count goes up.

Read the whole story beside your list

Click a title and its preview docks on the right: the description and its comments, rendered from Markdown with headings, checklists, code and links. Edit the description or add a comment from there.

Keep the board honest, in one click

Project Boards lists the draft cards on your GitHub project boards, board by board, with their status. Move one on and the board on GitHub is up to date for everyone. Issues and pull requests on a board get the same button in their own lists.

Your day, right on the wallpaper

Summary, Issues, Pull requests, Project Boards and widgets you make yourself sit on your desktop, Small, Medium or Large. Arrange them in the window or drag them on the desktop; they update with the top bar, so a glance between windows is enough.

Everything assigned to you, without the tab hunt

Top-bar buttons

Issues, Pull requests and Project Boards as one tinted group or as tabs, each with its live count. One flat list across your accounts, grouped by project, platform or organization; closed items are counted at the bottom. Menus keep a steady width sized to your screen.

Act where you are

Comment, close or reopen, edit assignees, labels and custom fields, and move items between statuses on your project boards, from the top bar or the window. Comment opens a box right under the item; the ⋮ menu copies references and links.

Every account, self-hosted too

Add several GitHub and GitLab accounts; their items show together in one list. A guided setup connects GitHub Enterprise Server and GitLab self-managed, and counts add up across them all.

Main window

A slim sidebar: Glance for your widgets and top bar, Tasks for All Tasks, Issues, Pull requests and Project Boards, and Settings with a page for Accounts, Preferences, Startup and About, each opening its menu right beside it. Click a title to preview it, Markdown rendered and comments as a feed. A red ! on Refresh says what failed and how to fix it.

Desktop widgets

Summary, Issues, Pull requests and Project Boards cards, or ones you make from filters, on your desktop. Arrange them in the window, set each one's size, opacity and where they sit, and set the wallpaper they're made for in one click.

Private by design

On github.com, sign in through a GitHub App limited to issues, pull requests and projects: no code access. Tokens stay in the GNOME keyring, and self-hosted instances need HTTPS unless they're on your local network.

Search your lists

One box, always on the right of the window's title bar, filters issues, pull requests and project items by title, repo, number, label or person, with match counts. Clear it to see everything again.

One-click updates

A notification at login says when a new version is out, with what's new. Install downloads the new Setup, checks its SHA-256 checksum and updates Source Glance, with no need to log out.

Open source

Apache 2.0 licensed. Public repositories you don't own show up without any setup. Report an issue or contribute.

Install in three steps

  1. Download Setup

    Source Glance Setup for Intel/AMD works on most PCs; there's also a build for ARM.

  2. Allow it to run

    In Files, right-click the download, choose Properties and turn on Executable as Program.

  3. Run the wizard

    Double-click it and follow the steps. Run it again any time to repair or remove Source Glance.

Check the download (recommended)

Download SHA256SUMS into the same folder and run:

sha256sum --check --ignore-missing SHA256SUMS

Every release is built by GitHub Actions with a provenance attestation. See the install guide.

Needs GNOME Shell 46–50 (Ubuntu 24.04 or newer) and a GitHub or GitLab account.

Update, repair or remove

One Setup file does it all: install, update, repair or remove. Run the latest Setup and it updates the Source Glance you have in place, keeping your settings and sign-ins. The new version starts right away, with no need to log out.

Easier still: when a newer version is out, a notification says so when you log in, with short release notes; Install starts the update. The window also shows Update available in its title bar. Click it and Source Glance downloads the new Setup, checks it against the release's SHA-256 checksums and opens it; when Setup finishes, the window reopens on the new version. Turn the check off in Settings. (Coming from v0.2.0 or earlier, log out once after updating.)
