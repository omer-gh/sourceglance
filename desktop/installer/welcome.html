Welcome to Source Glance @VERSION@

Source Glance keeps your GitHub and GitLab issues, pull requests and project boards one click away in the menu bar.

This installer:

  • puts Source Glance in the Applications folder in your home folder;
  • installs it for you only, so it doesn't need an administrator password;
  • changes nothing else on your Mac and runs no scripts.

Installing again later updates it. To remove it, open Source Glance, click Settings, then Uninstall Source Glance.
